# Dell Color Laser 1320c — native macOS driver

An open-source CUPS driver for the **Dell Color Laser 1320c**, built natively
for Apple Silicon and Intel Macs.

The 1320c is a rebadged **Fuji Xerox DocuPrint C525 A-AP**. Neither vendor
makes a current macOS driver:
- The Fuji Xerox driver that people use with it on modern macOS is Intel-only,
  so it needs Rosetta, which Apple is phasing out.
- Dell's own 2008 driver is PowerPC/i386 and no longer runs at all.

This driver doesn't need either of them.

> **Tested on:** one Dell 1320c over USB, macOS 15 (Apple Silicon). The Fuji
> Xerox DocuPrint C525 A-AP is the same printer, so it should also work,
> but that is untested. Reports welcome.

## How it works

The printer speaks **HBPL version 1**:
- a PJL job header
- tagged binary records
- per page, an image compressed with Fuji Xerox's *LRLE2* scheme: run copying
  in five directions plus Huffman-coded literal differences

It receives 8-bit RGB (colour) or 8-bit grey (black) and does its own colour
separation and halftoning.

The 1320c uses a variant that, as far as I know, no open-source driver
supported until now:
- a 24-byte image header
- a single bitstream with the literal differences interleaved
- 2-D page borders (column 0 predicts from a fixed border value)

| File | What it is |
|---|---|
| `src/rastertodell1320c.c` | The CUPS filter. Its run/literal encoder is derived from `foo2hbpl1` by Dave Coffin ([foo2zjs](https://github.com/koenkooi/foo2zjs)). |
| `ppd/Dell_Color_Laser_1320c.ppd` | Generated by `tools/genppd.py`. Uses Dell's option names and printer ID, so macOS matches the printer automatically. |
| `src/lut_data.h` | Colour correction for each "Image Types" setting, as 33×33×33 tables. |
| `tools/hbpl1x.c` | Decoder for the 1320c's format, used by the tests. |
| `tools/measure_luts.sh`, `tools/genlut.py` | How the colour tables were measured. |

### Where the data comes from

- **Job and page headers:** mapped by running the Fuji Xerox driver with every
  option and comparing the PJL/HBPL it sent.
- **Colour tables:** the Fuji Xerox driver's RGB→RGB colour correction,
  *measured* by passing synthetic colour grids through it and decoding the
  output. No vendor code or vendor files are included.

## Requirements

- macOS 12 or later. The build is universal (arm64 + x86_64).
- Xcode Command Line Tools to build: `xcode-select --install`.

## Install

```bash
make
sudo ./install.sh
```

This installs the filter to `/Library/Printers/Dell1320c` and the PPD to
`/Library/Printers/PPDs`. It then adds a queue called **`Dell_1320c_Native`**
on the printer's USB address, next to any existing queue.

To make it your main printer and remove the old Fuji Xerox driver, run
`sudo ./switch_to_native.sh`. It shares the native queue, makes it the
default, removes the `Dell_Color_Laser_1320c` queue, and removes Fuji's
driver unless another queue still uses it. Back up
`/Library/Printers/FujiXerox` first if you might want it back.

To uninstall: `sudo ./uninstall.sh`.

## Options

| Option | Choices |
|---|---|
| Paper sizes | A4, Letter, Legal, Executive, Folio, A5, B5, postcard, and #10, Monarch, DL, C5 and C6 envelopes |
| Paper source | Auto, Tray 1, Manual feeder |
| Paper type | Separate settings for Tray 1 and the manual feeder |
| Colour | Colour or black (`ColorModel` RGB/Gray) |
| Resolution | 600 or 300 dpi |
| Image Types | Normal, Photo, Presentation, Web, POP, Off |
| Other | Draft mode, skip blank pages, rotate 180°, collated copies |

AirPrint: macOS shares the queue on the network. iPhones and iPads only see it
as an AirPrint printer if something advertises it for AirPrint (for example
[AirPrint Bridge](https://github.com/sapireli/AirPrint_Bridge)). Because the
colour option uses the standard `ColorModel` name, such tools detect it as a
colour printer.

## Tests

```bash
make test
```

- **PPD check** with `cupstestppd`.
- **Lossless round trip:** synthetic pages (colour and mono, several sizes,
  both resolutions) are encoded and then decoded, and must come back
  byte-identical.
- **Comparison with the Fuji Xerox driver**, only if it's installed: 17 option
  combinations must produce identical headers and agreeing pages. On the
  author's printer, every case matched, and photo colours were within about
  1/255 on average.

## Not reproduced

- The Fuji filter's host-side edge-enhancement pass, which only affects
  pixels next to colour edges.
- Some Japanese envelope sizes and custom page sizes, whose printer codes
  couldn't be verified.
